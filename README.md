## Project setup
```
npm install
```

### Compiles and hot-reloads for development
```
npm run serve
```

## Docker

### Contrua a imagem do docker
```
docker build -t front-facilitaai 
```

### Inicie o contêiner
```
docker run -p 8080:8080 
```
### Acesse 
[http://localhost:8080](http://localhost:8080)
